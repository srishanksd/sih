# VAJRA-CSDD / PS84

Prototype architecture for SIH26084: convective-scale 0–6 hour nowcasting.

## Architecture

The repository separates the current executable radar ConvLSTM training path from the broader VAJRA-CSDD model architecture:

- multimodal observation fusion
- reliability-aware state estimation
- explicit convective state
- storm-cell graph
- Lagrangian storm-object dynamics
- Eulerian field dynamics
- object–field consistency
- storm lifecycle events
- stochastic ensemble uncertainty
- probabilistic multi-hazard heads
- predictability horizon
- downstream impact layer
- dashboard/API integration

The current radar training path is under `training/` and uses DWR NetCDF -> Cartesian DBZ -> ConvLSTM forecasting.

## Local development

```powershell
.\.venv\Scripts\python.exe main.py
```

Dashboard: `http://127.0.0.1:5000`

## Training

The current training entry point is intentionally kept separate:

```powershell
.\.venv\Scripts\python.exe training\train.py
```

Training data and checkpoints are local-only and are excluded from Git.

For the NVIDIA RTX 5050 development machine, the environment uses the CUDA-enabled PyTorch build. The exact local installation is machine-specific; do not commit the virtual environment or model weights.

## Repository data policy

The following are intentionally excluded from Git:

- raw DWR/INSAT/ILDN/AWS/GFS/ERA5 data
- processed `.npy` datasets
- split manifests generated from local data
- trained `.pt`/`.pth`/`.ckpt` weights
- Python virtual environments
- caches and generated bytecode

This keeps the repository suitable for source inspection and architecture visualization tools such as GitDiagram.

## Current model status

A radar-only ConvLSTM baseline has been implemented and trained as an initial pipeline validation. The broader multimodal VAJRA-CSDD modules are represented as modular architecture components; they should not be interpreted as fully trained multimodal production models yet.
